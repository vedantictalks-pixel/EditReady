## Download EditReady

Pick the file for your computer, then open it. Nothing else to install.

| Your computer | Download |
|---|---|
| Mac with Apple chip (M1, M2, M3, M4 and newer) | **EditReady-Mac-AppleSilicon.dmg** |
| Mac with Intel chip (older Macs) | **EditReady-Mac-Intel.dmg** |
| Windows 10 or 11 | **EditReady-Setup-Windows.exe** |
| Windows, no install (portable) | EditReady-Windows-Portable.zip |
| Linux (64-bit) | EditReady-Linux-x64.tar.gz |

Not sure which Mac you have? Click the Apple menu, then **About This Mac**. "Chip: Apple" means Apple chip. "Processor: Intel" means Intel.

**Mac:** open the .dmg and drag EditReady into Applications. The first time, macOS says it can't check the app. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only do this once.

**Windows:** run the setup file. If Windows SmartScreen appears, click **More info → Run anyway**. You only do this once.

**Linux:** extract the archive and run `EditReady/EditReady`. It opens in your web browser.

Then paste a link and click **Download**. EditReady keeps its download engine up to date by itself.

Please download only videos you own or have permission to use.
